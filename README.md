Личный сайт-портфолио и отдельная страница каталога Telegram-аккаунтов. Проект сделан как статический сайт: без сборщика, фреймворков и серверной части.

**Каталог:** https://chcode-us.github.io/site/telegram-accounts/  
**GitHub:** https://github.com/chcode-us  
**Связь:** [@vlaidst в Telegram](https://t.me/vlaidst)

## Структура проекта

```text
site/
├── index.html                  # Главная страница портфолио
├── accounts.html               # Перенаправление на новый адрес каталога
├── favicon.svg                 # Иконка сайта
├── telegram-accounts/
│   └── index.html              # Каталог Telegram-аккаунтов
├── README.md
└── LICENSE
```

Стили и JavaScript находятся внутри HTML-файлов. Для запуска сайта не требуется установка пакетов.

## Технологии

- **HTML5** — структура страниц.
- **CSS3** — оформление, адаптивная сетка, анимации и эффекты наведения.
- **JavaScript без библиотек** — мобильное меню, плавная прокрутка, появление блоков при прокрутке, слайдер Digital Lab и интерактивные карточки.
- **Google Fonts** — шрифты Manrope, Space Grotesk и DM Mono.

Внешние зависимости для сборки отсутствуют. Шрифты загружаются из Google Fonts при наличии подключения к интернету.

## Запуск на компьютере

Можно открыть `index.html` напрямую в браузере. Для локальной проверки удобнее запустить простой HTTP-сервер.

Из корневой папки проекта выполните:

```bash
python -m http.server 8000
```

Затем откройте:

```text
http://localhost:8000/
```

Каталог будет доступен по адресу:

```text
http://localhost:8000/telegram-accounts/
```

Остановка локального сервера — `Ctrl + C` в терминале.

## Публикация

Сайт размещён на **GitHub Pages** из ветки `main`.

После отправки изменений в репозиторий GitHub Pages автоматически обновляет опубликованную версию. Иногда обновление занимает несколько минут; если браузер показывает старую страницу, обновите её без использования кеша.

## Как вносить изменения

- Главная страница и её стили — `index.html`.
- Страница каталога — `telegram-accounts/index.html`.
- Иконка вкладки браузера — `favicon.svg`.
- Описание проекта — `README.md`.

Файл `accounts.html` оставлен для совместимости со старой ссылкой и перенаправляет посетителей на новый адрес каталога. Его не нужно использовать как основную страницу магазина.

При изменении структуры страниц проверьте ссылки между ними и откройте сайт на компьютере и телефоне.

## Релиз 1.2.0 — Самарский отсчёт
