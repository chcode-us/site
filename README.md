## 🎨 Design philosophy

I don't want interfaces to look like they were generated from the same template.

My approach:

```text
┌─────────────────────────────────────┐
│                                     │
│        FUNCTIONALITY                │
│              +                      │
│           DESIGN                   │
│              +                      │
│          PERSONALITY               │
│              ↓                      │
│          EXPERIENCE                │
│                                     │
└─────────────────────────────────────┘
```

Every interface should have its own character.

## ⚙️ Running locally

Clone the repository:

```bash
git clone https://github.com/chcode-us/site.git
```

Enter the directory:

```bash
cd site
```

Then simply open:

```text
index.html
```

No build system.

No framework.

No unnecessary dependencies.

Just open and run.
